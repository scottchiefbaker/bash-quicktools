Small tools, useful archives

Make a copy.
Keep the original.

Quicktools is a set of small Bash scripts for creating timestamped compressed copies and archives, then checking how files or folders have changed.

Three scripts, three jobs

qfb — one file at a time

Compresses each file separately with gzip, xz, or zstd. Keeps the source unless you ask to remove it.

qtar — tar archives

Packs files and directories together. Choose zstd, gzip, xz, bzip2, or no compression; optionally write a SHA-256 checksum.

qzip — zip archives

Packs files and directories into a zip, with optional exclusions and a SHA-256 checksum.

By default, archives go in /var/tmp and include a timestamp in their name. Use -o DIR to choose another output directory.

A few examples

Run these from the directory containing the scripts (or put the scripts on your PATH):

# Compress one file with the default format (gzip); keep the original
./qfb notes.txt

# Use xz, verify the archive, then remove the original after success
./qfb -c xz -t -r notes.txt

# Make a compressed tar archive of a project, with a checksum
./qtar -s projects/

# Make a zip and leave out log files
./qzip -x '*.log' projects/

# Preview the tar command without creating an archive
./qtar -N projects/

Compare against an archive

qfb can compare a file with its newest matching compressed copy; qtar can compare a directory with its newest matching tar archive. Both show a diff when things changed.

./qfb --diff notes.txt
./qtar --diff projects/

Heads up: diff mode searches the output directory (default /var/tmp). It supports qfb and qtar archives, not zip archives.

Getting started

These are standalone Bash scripts—no build or package manager is needed. Make sure the scripts are executable, then run ./qfb -h, ./qtar -h, or ./qzip -h for all options. Install the command-line tools for the archive formats you use (such as gzip, xz, zstd, tar, and zip).

Names have minute-level timestamps, so two runs for the same input within one minute can overwrite each other. For repeatable comparisons, keep the input name consistent and use the same output directory.
